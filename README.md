# Mi Portafolio Web

Sitio web personal desarrollado para presentar mi perfil como desarrollador web, mis tecnologías principales y mis proyectos destacados.

## Demo

- Sitio en producción: [Aquí pondrás tu enlace de GitHub Pages]
- Proyecto destacado: [LumaCraft](https://lumacraft.lat)

## Tecnologías

- HTML5
- CSS3
- JavaScript
- Diseño responsive
- Navegación suave con JavaScript

## Estructura del proyecto

```bash
mi-portafolio/
├── index.html
├── styles.css
├── script.js
└── README.md
```

## Cómo usarlo en local

1. Descarga o clona este repositorio.
2. Abre `index.html` en tu navegador.
3. Si usas VS Code, puedes abrirlo con Live Server.

## Personalización

Puedes editar este proyecto para cambiar:

- Nombre y presentación
- Proyectos destacados
- Habilidades
- Botones y enlaces
- Colores y estilos

## Publicación con GitHub Pages

1. Ve a `Settings`
2. Entra a `Pages`
3. En `Source`, elige `Deploy from a branch`
4. Selecciona la rama `main`
5. Guarda los cambios

GitHub generará una URL pública para tu sitio.
